# Gemini GenAI Monorepo (Turborepo)

A monorepo workspace structured using [Turborepo](https://turborepo.dev/) that builds a frontend application integrated with the Google GenAI SDK (`@google/genai`). It features a Data Structures and Algorithms (DSA) tutor chatbot and an automated web app builder agent.

---

## 📂 Project Structure

This monorepo separates logic and UI into applications (`apps/`) and shared packages (`packages/`):

### Applications (`apps/`)
* **[client](file:///Users/sudhanshumishra/code/genai/p1/apps/client)**: The active Next.js (version 16) chat client.
  * Employs Material-UI (MUI v9) for components and `@emotion` for styling.
  * Connects to the local API routes for invoking Gemini.
* **[web](file:///Users/sudhanshumishra/code/genai/p1/apps/web)**: A boilerplate Next.js landing application generated by Turborepo.

### Packages (`packages/`)
* **[ui](file:///Users/sudhanshumishra/code/genai/p1/packages/ui)**: Reusable React components:
  * **[chatbot.tsx](file:///Users/sudhanshumishra/code/genai/p1/packages/ui/component/chatbot.tsx)**: A light-themed modular chat component with automated scrolling and sidebar integration.
  * Inputs, outputs, and basic login/signup layouts.
* **[functions](file:///Users/sudhanshumishra/code/genai/p1/packages/functions)**: Core business logic functions and Gemini tools:
  * **[numerical](file:///Users/sudhanshumishra/code/genai/p1/packages/functions/numerical)**: Contains `prime` (checks prime numbers) and `sum` (adds numbers) functions along with their respective Gemini Function Declarations.
  * **[commandRunner](file:///Users/sudhanshumishra/code/genai/p1/packages/functions/commandRunner)**: Exposes `executeCommand` to run terminal shell commands (used by the AI Agent to build files and apps locally).

## 🔌 API Endpoints (`apps/client`)

The application configures two distinct Gemini 2.5 Flash chatbot agents:

### 1. DSA Instructor Chatbot (`/api/chat`)
* **File**: [apps/client/src/pages/api/chat/index.ts](file:///Users/sudhanshumishra/code/genai/p1/apps/client/src/pages/api/chat/index.ts)
* **Description**: A dedicated tutor that answers questions strictly relating to **Data Structures & Algorithms** and **Competitive Programming**.
* **Behavior Rules**:
  * Provides optimal solutions, explaining key concepts clearly with time and space complexity details.
  * **Fallback**: If you ask questions unrelated to DSA, it will politely decline and reply with a **Bhagavad Geeta shloka in Hindi** along with a simple translation/explanation.
  * **Functions/Tools**: Has access to the shared `prime` and `sum` numerical tools.

### 2. App-Builder AI Agent (`/api/chat/agent`)
* **File**: [apps/client/src/pages/api/chat/agent.ts](file:///Users/sudhanshumishra/code/genai/p1/apps/client/src/pages/api/chat/agent.ts)
* **Description**: An AI system configured to write, structure, and deploy minor applications locally based on user prompts.
* **Functions/Tools**: Has access to the `executeCommand` tool. It generates terminal commands step-by-step (e.g. `mkdir`, creating HTML/CSS/JS files, writing script code) and executes them directly on the system, returning progress logs and details back to the interface.

## 🛠️ Getting Started

### 1. Prerequisites
Make sure you have Node.js and a package manager installed.

### 2. Environment Variables
Create an `.env` or `.env.local` file inside `apps/client/` (or in the root folder if configured) and add your Google Gemini API key:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```

### 3. Installation
Install all dependencies from the root directory:
```bash
npm install
```

### 4. Running the Project
Start all applications in development mode using Turborepo:
```bash
npm run dev
```
The console will host:
* The primary client application at `http://localhost:3000` (or the fallback active port).
* The web boilerplate starter.

## ⚡ Development & Build Scripts
Run commands using your global or local Turborepo setup:

* **Build all workspaces**:
  ```bash
  npx turbo build
  ```
* **Lint codebase**:
  ```bash
  npx turbo lint
  ```
* **Dev specific workspace** (e.g. `client`):
  ```bash
  npx turbo dev --filter=client
  ```
